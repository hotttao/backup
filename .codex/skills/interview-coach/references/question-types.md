# 面试题类型与生成策略

## 技术岗位题型

### 1. 算法编程题

**适用**：软件工程师、后端、前端

**生成策略**：

- 从简历项目中提取相关数据结构场景
- 匹配 JD 中提到的技术栈
- 难度递进：Easy → Medium → Hard

**模板**：

```
### 编程题: [题目名称]

**题目描述**:
[问题描述]

**示例**:
输入: [示例输入]
输出: [示例输出]

**约束**:
- [约束条件]

**考察点**: [数据结构/算法]
**时间要求**: [建议时间]

<details>
<summary>💻 代码模板</summary>

\`\`\`python
def solution(params):
    # 在这里实现你的解答
    pass

# 测试用例
assert solution(test_input) == expected_output
\`\`\`

</details>

<details>
<summary>💡 思路提示</summary>

1. [第一步提示]
2. [第二步提示]
3. [优化方向]

</details>
```

### 2. 系统设计题

**适用**：高级工程师、架构师、Tech Lead

**生成策略**：

- 基于简历中的大规模系统经验
- 对标 JD 中的系统规模要求
- 从小到大逐步扩展

**模板**：

```
### 系统设计: [系统名称]

**背景**:
[业务场景描述]

**要求**:
- 功能需求: [核心功能列表]
- 非功能需求: [QPS/延迟/可用性]

**讨论要点**:
1. 整体架构设计
2. 核心组件选型
3. 数据存储方案
4. 扩展性考虑
5. 容错与高可用

<details>
<summary>💡 参考要点</summary>

**架构图要素**:
[核心组件及其关系]

**关键决策**:
- [决策点1]: [方案对比]
- [决策点2]: [方案对比]

**扩展问题**:
- 如果 QPS 增长 10 倍？
- 如果要支持多地域？

</details>
```

### 3. 项目深挖题

**适用**：所有技术岗位

**生成策略**：

- 直接从简历项目中提取
- 按 STAR 法则设计追问
- 关注技术选型和困难克服

**模板**：

```
### 项目深挖: [项目名称]

**开场**:
"我看到你简历上写了[项目名]，能详细介绍一下吗？"

**追问方向**:

1. **Situation/背景**
   - 这个项目的业务背景是什么？
   - 为什么要做这个项目？

2. **Task/任务**
   - 你在项目中的角色是什么？
   - 主要负责哪些模块？

3. **Action/行动**
   - 技术选型是怎么考虑的？
   - 遇到了哪些技术难点？
   - 怎么解决的？

4. **Result/结果**
   - 最终效果如何？
   - 有没有量化的指标？
   - 学到了什么？

<details>
<summary>💡 回答要点</summary>

**好的回答特征**:
- 有具体数据支撑
- 能解释技术决策的原因
- 承认困难并展示解决过程
- 有反思和总结

</details>
```

### 4. 行为面试题 (BQ)

**适用**：所有岗位，尤其是管理岗

**生成策略**：

- 匹配公司价值观和 Leadership Principles
- 从简历经历中寻找可能的情景
- 正面和负面情景都要覆盖

**常见主题**：

- 冲突处理
- 失败经历
- 领导力展现
- 困难决策
- 创新与改进

**模板**：

```
### 行为面试: [主题]

**问题**:
"请分享一个你[具体情景]的经历"

**考察点**:
- [能力/素质1]
- [能力/素质2]

**公司价值观关联**:
[如果是特定公司，关联其 Leadership Principle]

<details>
<summary>💡 STAR 回答框架</summary>

**Situation**: [描述背景 - 1-2句]
**Task**: [你的职责 - 1句]
**Action**: [你做了什么 - 重点，3-5句]
**Result**: [结果如何 - 带数据]

**注意事项**:
- 用"我"而非"我们"
- 具体行为而非泛泛而谈
- 即使是团队成果也要突出个人贡献

</details>
```

## 非技术岗位题型

### 产品经理

**核心题型**：

- 产品设计/改进
- 用户场景分析
- 数据指标设计
- 优先级决策
- 估算题 (Fermi)

### 数据分析师

**核心题型**：

- SQL 查询题
- A/B 测试设计
- 指标异常分析
- 数据可视化
- 业务洞察提取

### 运营/市场

**核心题型**：

- 活动策划
- 用户增长策略
- ROI 分析
- 危机公关处理
- 竞品分析
