## 推荐理解顺序

先掌握第 1～2 章的概念，再重点学习第 3 章水位；之后用第 4～5 章理解窗口和一致性，用第 6～9 章理解动态表、状态、SQL 和连接，最后用第 10 章建立技术演进全景。

最重要的一条主线是：

```text
事件时间 → 窗口分组 → 水位判断进度 → 触发输出 → 状态持续修正 → 检查点保证恢复
```
